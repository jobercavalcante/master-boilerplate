# Frontend Design

Use este skill para construir interfaces com identidade clara e boa hierarquia visual.

## Diretrizes

1. Escreva uma tese visual antes de codificar uma tela maior.
2. Preserve o sistema visual existente quando a feature estiver dentro de uma aplicação já desenhada.
3. Prefira layouts densos e funcionais para software operacional.
4. Use uma hierarquia clara de espaçamento, títulos e controles.
5. Evite UI genérica, hero inflado e cartões decorativos sem função.
6. Mantenha consistência entre estados vazio, carregando, erro e sucesso.

## Para Este Projeto

- A aplicação é Laravel + Inertia + React, então pense em páginas e formulários que recebem dados do backend.
- Priorize clareza, comparação e ação rápida.
- Use componentes existentes quando eles já resolvem o padrão visual.
- Para telas de cadastro/edição, mostre a estrutura de dados sem esconder campos importantes.
- Em áreas administrativas, prefira densidade com respiro controlado, não ornamentação.

## Checklist Visual

- A tipografia está legível e bem escalonada.
- Os controles principais estão fáceis de localizar.
- O layout não quebra em mobile.
- O texto cabe nos botões, tabelas e colunas.
- A cor reforça sem distrair.
