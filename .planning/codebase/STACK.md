# Stack Tecnológica

* **Backend:** Laravel 12+ (PHP)
* **Frontend:** React com Inertia.js
* **Estilização:** Tailwind CSS (Foco em Design Premium / Glassmorphism)
* **Banco de Dados:** SQLite (Desenvolvimento/Testes) e PostgreSQL/MySQL (Produção)
* **Testes:** PHPUnit / Pest (Feature Tests) e Laravel Dusk (E2E)
* **Padrões de Projeto:** Strict Thin Controllers, SOLID, FormRequests.
