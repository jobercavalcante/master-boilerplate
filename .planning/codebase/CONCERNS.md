# Concerns

* **Zero Code (Greenfield Boilerplate):** O projeto não possui código Laravel inicial ainda, é um boilerplate para arquitetura governada por IA.
* O maior risco é a IA desobedecer as regras `skills/` e gerar código sujo. Para evitar isso, deve-se reforçar a ingestão do `BOOTSTRAP.md` rigorosamente no início de cada projeto.
