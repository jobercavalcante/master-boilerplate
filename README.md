# Master Boilerplate Architect

**Autor:** Jober Cavalcante

Um boilerplate definitivo para inicialização de projetos "Greenfield" utilizando Inteligência Artificial (Agentes Autônomos ou Semi-Autônomos como Cursor, Copilot, Cline, Antigravity).

## O que isso faz?
Este repositório NÃO é um repositório de código fonte base tradicional. Em vez disso, ele é um **"Cérebro Arquitetural" (Architectural Brain)** projetado para ser consumido por IAs durante o setup inicial de um novo projeto.

Ele fornece um conjunto rígido de regras, padrões de design (Thin Controllers, SOLID), arquiteturas pré-definidas e a filosofia de design premium (Emil Kowalski) que a Inteligência Artificial deve seguir desde o primeiro commit. Quando você copia este boilerplate para um novo projeto e executa o **Master Prompt**, a IA automaticamente configura e implementa a stack **Laravel 12+, Inertia.js, React e Tailwind CSS**, respeitando todas as regras corporativas e padrões visuais.

## Stack Tecnológica Alvo
* **Backend:** Laravel 12+ (PHP)
* **Frontend:** Inertia.js com React
* **Estilização:** Tailwind CSS (com foco em micro-interações, glassmorphism e design premium de alta fidelidade)
* **Banco de Dados:** SQLite (Dev/Test) ou PostgreSQL/MySQL
* **Qualidade:** Testes E2E (Dusk), Feature Tests e FormRequests (Thin Controllers)

## Metodologia GSD (Get Shit Done)
Este boilerplate foi fortemente otimizado para trabalhar em conjunto com o framework **GSD (Get Shit Done)** e suas skills. Ele integra nativamente os fluxos de trabalho autônomos e semi-autônomos (como `gsd-map-codebase`, `gsd-execute-phase`, `gsd-plan-phase`, etc.), permitindo que a IA planeje entregas metodicamente, siga guidelines estritas e mantenha a base de conhecimento técnica e arquitetural sempre atualizada no diretório `.planning/`.

## Como Usar
1. Crie um novo repositório vazio.
2. Copie o conteúdo deste boilerplate para a raiz do seu novo projeto.
3. Abra seu assistente de IA (Cursor, Cline, etc) na raiz do projeto.
4. Abra o arquivo `BOOTSTRAP.md` e copie o **Master Prompt**.
5. Cole o **Master Prompt** no chat da IA e deixe-a orquestrar o setup do seu projeto!

## Estrutura do Boilerplate
* `BOOTSTRAP.md`: Contém o Master Prompt que "acorda" e instrui a IA.
* `skills/`: Diretório contendo diretrizes rigorosas (livro de regras) para a IA sobre como programar (ex: sem lógica em controllers, testes obrigatórios, design de interface premium).
* `system-design/`: Diretório destinado aos seus diagramas C4, modelos Entidade-Relacionamento e especificações de alto nível do que será construído.
